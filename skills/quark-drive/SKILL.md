# 夸克网盘（Yuntuan）

1. **确认官方实现。** 优先选用 [夸克官方 Skill/CLI](https://github.com/quark-clouddrive/quarkclouddrive_offical)，不直接实现非公开 Cookie/抓包 API，不自动执行网络上检索到的陌生脚本。
2. **安装、登录。** 管理员先审查官方安装包版本和脚本，在隔离环境中按官方说明安装并本人完成登录授权。Yuntuan 不通过 QQ 群消息代收二维码、Cookie、Token 或授权码。
3. **平台边界。** 官方仓库当前标注 macOS、Linux 与 Windows WSL，未声明 Windows 原生兼容；CLI 依赖 Node.js。执行前检查实际环境与版本，并读取真实 `--help` 支持的命令，不猜测 CLI 参数。
4. **查找与读取。** 在明确的目录/类型范围搜索，返回文件名、所在目录、大小和真实标识。阅读及 AI 总结功能依赖当前授权/会员权益，不能凭文件名生成虚构内容。
5. **上传与备份。** 仅允许从管理员授权的本地目录/任务产物中读取；检查文件大小、磁盘配额及目的目录，优先增量备份。成功后核查返回的文件标识；对同一备份周期进行去重。
6. **下载与转存。** 限制下载路径、文件大小、并发与网络权限；下载文件不允许变为可执行指令。转存共享链接前检查来源与目的目录。
7. **修改与分享。** 批量重命名、移动、覆盖、分享或删除先展示目标文件集合与影响，再要求有权账户主人的明确确认。支持撤销的操作可记录批次 ID，但不得承诺任意操作都可撤销。

## 安全与定时任务

- 把 QQ 用户、会话作用域、网盘授权账户分别绑定，不允许群友借用管理员网盘身份执行操作。
- 日志和模型输入中不得出现授权凭据、签名下载链接或本地敏感路径。
- 自动化执行仅限经明确批准的目录和操作类型；认证过期输出 `needs_auth`，权益不足输出可解释错误，不静默重试付费操作。
- 定时备份应记录任务编号、实际运行时间、上传成功/失败项，不把已排队误报为已完成。
